## Aderyn Low and Slither Low / Informational (not gated; reviewed in bulk)
- `centralization-risk`, `state-no-address-check`: the timelock / guardian roles of §7.4, by design.
- `ecrecover` malleability: the price feed and σ oracle use OZ `ECDSA.tryRecover` (rejects high-s), and require strictly
  ascending signers, so a malleated signature can neither replay nor double-count.
- `calls-loop`, `costly-loop`, `require-revert-in-loop`: bounded loops (≤ 64 markets, ≤ 128 positions per lot, ≤ 64 bids,
  ≤ 32 vault queue entries); gas measured in S3 (J3 batch, `settlePositions` 128).
- `timestamp`: the protocol is a clock; every comparison is against calendar or phase boundaries (INV-CLK-*).
- `reentrancy-benign`, `reentrancy-events`: guarded; see the reentrancy suites.
- `unchecked-return` (Aderyn): the same balance-delta / try-tip patterns as the Slither `unused-return` rows.
- `unused-error`, `unused-import`, `literal-instead-of-constant`, naming: style; left to BE-chain's NatSpec pass.
