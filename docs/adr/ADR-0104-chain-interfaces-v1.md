# ADR-0104 · BE-chain · Interfaces v1 (Sprint 2)

Status: Accepted · Date: 2026-09-28 · Owner: BE-chain

## Context

Sprint 2 builds the lending core (market, Senior Vault, rates, fees, reserve, treasury, tips, governance). The
backend (indexer, API, keeper) and the quant need the ABIs before the implementations exist. v0 (S1) is frozen
history in `deployments/abis/v0/` and is never re-exported.

## Decision

1. **Location.** `deployments/abis/v1/<Name>.json`, exported by `make abis-export` (`ABI_VERSION` now defaults to
   `v1`). `deployments/abis/v1/CHANGELOG.md` is generated by `contracts/script/abi_diff.py`, which fails if any v0
   entry disappears or changes other than the allowed break below. `make abis-check` runs it; CI runs it too.
2. **The one breaking change (R-25).** `ReportAccepted(bytes32 indexed asset, uint8 kind, uint256 price,
   uint40 observedAt, uint64 seq, uint8 marketStatus)`. Its topic0 differs from v0, so the indexer must use the v1
   ABI for feeds deployed from this commit on. `marketStatus` is `FeedMarketStatus` (0 closed, 1 pre, 2 regular,
   3 post, 4 overnight, 5 halted), exactly the signed report's field.
3. **Everything else is additive.** No v0 selector, event or error changed. New entries:
   - **Errors** appended to `ICredenceErrors` (so every ABI decodes them): lot / auction-position errors, vault
     queue errors, guardian errors. The list is in the changelog.
   - **Types**: `MarketWiring`, `LotInfo`, `RedeemRequest`, and two code tables:
     - `MarketAction` (the `action` of `ActionNotAllowedInState(uint8 action, ClockState s)`): 0 BORROW,
       1 WITHDRAW_COLLATERAL, 2 REPAY, 3 ADD_COLLATERAL, 4 BUY_COVER, 5 FLAG_FOR_AUCTION, 6 ENFORCE_BELL.
       REPAY and ADD_COLLATERAL never appear in a revert (P2); they exist for completeness.
     - `BellOutcome` (the `outcome` of `BellEnforced`): 0 SAFE, 1 ALREADY_COVERED, 2 AUTO_COVERED,
       3 PRECLOSE_THEN_COVER (R-03), 4 PRECLOSE_SALE.
   - **`ICredenceMarket`**: `initializeWiring(MarketWiring)` (once, by the deployer, §7.4), `setEngine` /
     `setOracle` (timelock, R-21), `setReserveFeeShare(uint16)` (timelock), and views `wiring`, `timelock`,
     `guardian`, `reserveFeeShareBps`, `marketIds` (creation order, for the indexer), `lotInfo`, `lotBorrowers`,
     `lotPosition`, `projectedDebt` (R-08), `upcomingClosureId`, `totalBorrowsAll`. Events `MarketWired`,
     `EngineSet`, `OracleSet`, `ReserveFeeShareSet`, `LotsReleased`, `LotCleared`, `Dequeued`.
   - **`ISeniorVault`**: `setAllocator`, `allocator`, `timelock`, `market`, `cap`, `supplyQueue`,
     `withdrawQueue`, `redeemRequest(id) → RedeemRequest`, `queueHead`, `nextRequestId`, `pendingRedeemShares`,
     `claimableAssets`; event `AllocatorSet`.
   - **`ICredenceGuardian`**: `initializeWiring(address[] markets, address clock)` (one market singleton per stack, R-01), the constants `UNPAUSE_DELAY` (6 h),
     `MAX_HALT` (7 d), `HAIRCUT_TTL` (7 d), `MAX_HAIRCUT_BPS` (1000), views `safe`, `timelock`, `markets`, `clock`,
     `unpauseBorrowAt`, `unpauseCoverAt`; events `CoverUnpauseScheduled`, `GuardianWired`.
   - **`IKeeperTips`**: `initializeWiring(address[] payers)` (once), `setPayer` (timelock), `isPayer`, `timelock`.
   - **`IProtocolReserve`**: `initializeWiring(market)`, `setTargetBps` / `targetBps` (target = max(floor,
     bps × Σ borrows), 500 = 5%, §8.10), views `market`, `treasury`, `token`, `timelock`; events `TargetBpsSet`,
     `MarketSet`.
   - **`ITreasury`**: views `token`, `tips`, `timelock`.
   - **`ISigmaOracle`**: `hashUpdate(SigmaUpdate)` (the EIP-712 digest, for keeper J7 cross-checks), `timelock`.
4. **Conventions the backend can rely on.**
   - `bytes32(0)` as a market id in `ICredenceGuardian.pauseBorrow` / `scheduleUnpauseBorrow` means ALL markets.
     The market stores it as the overlay of id `0`, and `overlay(bytes32(0))` returns it.
   - `pauseCover(target)` with `target == market` pauses cover on every market (global overlay). A pool target is
     an S3 concern.
   - `BellEnforced` is emitted once per processed borrower; SAFE / ALREADY_COVERED borrowers are skipped with no
     event and no tip.
   - Implementation ABIs (`CredenceMarket`, `SeniorVault`, `SigmaOracle`, `KeeperTips`, `Treasury`,
     `ProtocolReserve`, `CredenceGuardian`, `CredenceTimelock`) are added to `v1` when they land, with their own
     board READY. They only add constructors and admin functions to these interfaces.
5. **`IRiskEngine` is unchanged in v1.** If the engine is split for size (R-24), the split sits behind this same
   interface (see ADR-0106).

## Correction (same day, before any consumer)

`ICredenceGuardian.initializeWiring(address market, address clock)` / `market()` became
`initializeWiring(address[] markets, address clock)` / `markets()`: R-01 needs two stacks (equity, NAV), each with
its own `CredenceMarket`, and the shared `AssetClock` has one guardian. `GuardianWired(address[] markets, address clock)`.

## Consequences

The indexer switches `ReportAccepted` to the v1 signature. Everything else in v0 keeps decoding. Anything that
imports `ICredenceErrors` from v1 decodes every Credence revert, including the S2 ones.
